### 2026-10-11: Camry 50/70, Prius 55 (v8)
- **Camry-ийн үе.** 2017 онд XV50 (2017.06 хүртэл) ба XV70 (2017.07-оос) зэрэг гарсан. Энэ нь Camry-ийн алдааны гол эх үүсвэр байсан.
  - `tools/enrich.py` нь үеийг `cgen` (50/70/None) гэж тодорхойлно: 2018 болон хойш = 70, 2016 хүртэл = 50. 2017-ийнхийг тайлбараас уншина («Camry 70», «AXVH70», «сер2», «Camry 55», үйлдвэрлэсэн сар, WS комплектац).
  - 2017 оны зарын 60% нь үеэ бичдэггүй.
  - Шинж: `cam70` (+10.7%) ба `cam17unk`. Тодорхойгүй 2017 оны зарын үнэ (дундаж 47.5 сая) 70-тай адил байсан тул тооцоолуурт «Мэдэхгүй» сонголтыг 70 гэж тооцно.
  - Үр дүн: Camry-ийн алдаа 7.0% → 6.8% (давтан CV), 8.1% → 6.6% (тогтмол 5-fold).
- **Prius 55.** unegui.mn-ийн `toyota/Prius55/` ангиллаас 70 зар татсан (`data/unegui_prius55_2026-10-11.json`, 25 нь дугаар аваагүй). Prius 50/51-ийн бүлэгт `is55` шинжтэй оруулсан.
  - Загвараар Prius 50-аас +13.8%, 4WD-тэй нийлээд +17.3% үнэтэй. Бодит дундаж үнээр 2016–2017 онд +17–20% байна.
  - Prius 55-ийн алдаа 6.2%. Prius 50/51-ийн алдаа 4.9% хэвээр.
- Prepped файлуудад `cgen`, `is55` нэмэгдсэн (нөөц: `data/_backup_prepped_2026-10-11/`). Дахин татсан бол `python tools/enrich.py <огноонууд>`-ыг ажиллуулна.
- `compare_and_refit.GEN = True` бол шинэ шинжүүд ордог. `tools/eval_gen.py` нь шинжтэй ба шинжгүй хувилбарыг давтан CV-ээр харьцуулна.
- Тооцоолуурыг `tools/patches/patch_v8.py`-аар шинэчилсэн (нөөц: `reports/unelgee_v7_backup.html`). Патчийг дахин ажиллуулах бол эхлээд v7 нөөцийг сэргээнэ, эс бөгөөс давхар оруулна.

## Түүхий өгөгдөл хаана байна

**2026-10-04-нөөс хойш дискэнд хадгалагдсан** (`data/`):
- `unegui_toyota_2026-10-01.json` (D, D2), `unegui_toyota_2026-10-04.json` (D3): түүхий зарууд.

- `compare_*.json`, `robustness_*.json`: харьцуулалтын үр дүн.

Дараагийн шинэчлэл (жишээ нь 11-р сарын эхээр):
1. unegui.mn-ийн дэлгэрэнгүй хуудас одоо `<dt>/<dd>` бүтэцтэй. 10.04-ний татлагыг ийм уншигчаар хийсэн (`scrape_and_fit.js`-ийн хуучин текст уншигч биш). Claude-д "үнийн шалгалтыг дахин хий" гэвэл ижил аргаар татна.
2. `python tools/compare_and_refit.py 2026-10-04 <шинэ огноо>` → харьцуулалт + шинэ загвар.
3. `python tools/robustness_check.py ...` → λ, шинжийн тест.
4. `tools/patches/patch_v6.py`-г шинэ огноо, файлын нэрээр тохируулж тооцоолуурыг шинэчилнэ.

Хуучин тэмдэглэл:

- Татсан зарууд Chrome-ын unegui.mn сайтын IndexedDB-д `carval` нэрээр хадгалагдсан:
  - `D2` = бүх талбартай 2,037 зар.
  - `D` = өмнөх татлага.
- Хөтчийн өгөгдлийг цэвэрлэвэл устана. Иймд `tools/export_data.js`-ээр JSON файл болгож `data/` хавтсанд хадгална.
