# data/midas-photos/

Midas Motors-ын машины зургууд. Гаалиас, талбайгаас авсан түүхий зургийг шууд оруулж болно. Загвар нь зургийг өөрөө тайрч, багтаана.

```
data/midas-photos/car1/1.jpg   ← гол зураг (3/4 урд өнцөг)
data/midas-photos/car1/2.jpg   ← хажуу
data/midas-photos/car1/3.jpg   ← ар тал
data/midas-photos/car1/4.jpg   ← салон, одометр …
```

Файлын замыг `data/midas-examples.json` (эсвэл `data/midas-cars.json`)-ийн `photos` / `photo` талбарт бичнэ. Улсын дугаар харагдаж байвал бүдгэрүүлсэн байх ёстой.

Зургийн тохиргоо (`photo` эсвэл `photos`-ийн мөр бүрт):

- `"pos": "50% 40%"` — аль хэсгийг төвд нь харуулах (хэвтээ / босоо).
- `"scale": 1.1` — бага зэрэг томруулж захыг нь тайрах.
- `"fit": "contain"` — зургийг тайрахгүй бүтнээр нь харуулж, хоосон зайг бүдэг дэвсгэрээр дүүргэнэ (аукшны 4:3 зурагт тохиромжтой).

## Бүрсгэр зургийг сайжруулах

Аукшны, гаражийн зураг ихэвчлэн бүрсгэр, хар машин нь хөхөвтөр харагддаг. Энэ скрипт бүрсгэр байдлыг арилгаж, хар будгийг тод хар болгоно. Мөн улсын дугаарыг бүдгэрүүлж, постерт тохирох хэмжээнд (1600px) томруулна.

```
pip install opencv-python-headless
python3 templates/midas-motors/tools/enhance_photo.py эх.png data/midas-photos/машин/1.jpg --plate x0,y0,x1,y1
```

`--strength 0.7` илүү зөөлөн (салоны зурагт), `--strength 1.3` маш бүрсгэр зурагт.

Дилерийн усан тэмдэгтэй (BE FORWARD г.м.) зургийг `--crop x0,y0,x1,y1`-ээр тайрна. Жишээ нь 640×480 зургийн доод бичгийг хасахдаа `--crop 0,0,640,450`. `--plate` координатыг тайраагүй эх зургаас нь авна.
